# 通知与推送

在「设置 → 通知与推送」添加个人渠道。渠道可以单独启停，勾选「转发所有通知类型」或选择具体类型。同一提醒可以在多个渠道收到。站内已读状态与投递状态各自记录。

## 渠道

| 类型 | 填写方式 |
|---|---|
| Bark | 填设备 Key，留空服务地址使用官方服务。自建服务可填完整地址，例如 `http://192.168.1.20:8080/bark`，也可分开填协议、主机、端口和路径。系统调用 `/push` JSON 接口。分组和铃声可填入可选参数，例如 `{"group":"家账簿","sound":"bell"}`。 |
| Server 酱 | 只填 SendKey 时自动选择 Turbo 或 Server 酱³，并从 Server 酱³ 的 SendKey 提取 UID。粘贴已包含 SendKey 的完整 `.send` 地址时，直接使用该地址，SendKey 栏可留空。自建服务也可填基址或用 `{key}` 指定密钥位置。服务返回业务成功后才标记接受。 |
| 通用 Webhook | 可填完整 HTTP/HTTPS URL，或填写协议、域名/IP、端口和路径。GET 用 Query，POST 可选 JSON 或表单。Query、请求头和请求体均用 JSON 对象填写。 |

模板可用 `{{title}}`、`{{content}}`、`{{event_type}}`、`{{amount}}`、`{{date}}`、`{{url}}`。没有相应业务数据时变量为空。编辑时留空保留旧凭据。「发送测试通知」会发一条真实但不含账目数据的消息。成功表示服务已接受，手机是否展示取决于渠道与设备设置。[Server 酱官方接口](https://sct.ftqq.com/docs/getting-started/sendkey/) · [Bark API](https://github.com/Finb/bark-server/blob/master/docs/API_V2.md)

自建局域网服务需由部署者在服务环境设置 `HOMELEDGER_PUSH_LAN_TARGETS`，填写以逗号分隔的完整来源，例如 `http://192.168.1.20:8080,http://bark.home:9000`。使用默认端口时可省略端口。部署后需重载进程。网络层会固定经过检查的目标 IP，拒绝重定向、回环、链路本地和其他保留地址。

使用代理的 Fake-IP DNS 时，Server 酱 Turbo、Server 酱³ 和 Bark 官方 HTTPS 域名可通过代理虚拟地址建立连接，仍需通过官方域名的证书校验。自定义服务遇到虚拟 IP 提示时，需要让部署机器的 DNS 为该域名返回真实地址。

渠道配置加密保存在 SQLite。默认密钥文件位于数据目录的 `.notification-key`，也可使用部署环境中的 `HOMELEDGER_PUSH_KEY`，值为 64 位十六进制随机密钥。迁移部署需要单独安全备份密钥。仅恢复 SQLite 不会带回密钥。密钥不可用时，原账务和站内通知仍可使用。

## 配置及验证提醒

1. **订阅** 在订阅页把「提前提醒（天）」设为 2，在渠道中选择「订阅即将扣费」。用续费日为本地日期后两天的隔离演示订阅验证。一次到期只生成一次该提醒，试用结束和到期待确认是独立类型。
2. **当天消费** 账本管理员填写每日预算和比例，例如 ¥300 和 80%，可选择全账本、分类或账户。按记账日期统计已确认支出和费用，单独入账的退款另计。用两笔合计 ¥240 的消费验证首次达到阈值。继续增加消费时，待次日重新累计后才可能再次提醒。
3. **信用卡出账** 先配置卡的账单日和还款日，再在提醒设置选择提前天数，填 0 表示当天。账单金额未确认时，仅显示可确定的日期等信息。
4. **信用卡还款** 使用已有的还款提醒开关。提醒天数可指定 `7,3,1,0`，分别表示提前 7、3、1 天及当天，留空使用原有提醒规则。以存在待还金额的已出账卡验证，结清后待发送的还款提醒会跳过。

后台启动后检查，并约每 15 秒扫描已提交站内通知和日消费数据。其他定时提醒由现有调度器生成。启停或更新渠道时以保存后的新消息为准。暂时失败最多三次尝试，发送后响应超时等情况记录为「结果未知」。安静时段内投递保留在队列，到时重新检查有效性，已经跨天的消费预警不会再发。隐藏金额时手机正文仅提供通知类型，金额模板为空。

## 开放 API

开放 API 使用原有账本 Bearer 令牌。请求结果始终受当前成员权限及令牌绑定账本限制。个人渠道、凭据和渠道测试在登录后的网页设置中管理。

| 方法与路径 | 说明 |
|---|---|
| `GET /api/open/notifications?limit=50` | 查看令牌用户在绑定账本的通知，最多 100 条。 |
| `GET /api/open/notifications/rules` | 查看每日预警和已配置账期的信用卡提醒。 |
| `POST /api/open/notifications/rules/daily` | 账本管理员保存 `budget_cents`、`alert_pct`、`enabled`、`timezone` 和 `scope`。范围为 `overall`、`category` 或 `account`，后两者分别填 `category_id`、`account_id`。 |
| `POST /api/open/notifications/rules/cards/:id` | 账本管理员保存信用卡提醒。字段为 `closing_days`、`repayment_days`（整数数组）、`send_time`（如 `09:00`）和 `timezone`。两个提前量字段分别传 `null` 时停用出账提醒或恢复原还款规则。 |
