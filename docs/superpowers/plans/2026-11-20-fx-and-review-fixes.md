# 外币信用卡与七项审查修复

**确认口径** 该信用卡以人民币还款，保存原币金额并以入账时的人民币折算归集，实际入账有出入时走正常账务更正。启用入口继续保存银行账期规则。

- 程序以周期获取并缓存最新公开参考汇率，记录入账所用汇率。人民币流水照常处理，旧交易保存的汇率不因行情更新而变化。用模拟行情验证缓存、自动和手填汇率。
- 账户余额根据账户币种计算，资产和趋势换算到账本本位币，两处使用一致的计入净资产范围。人民币卡以本位币折算额归集外币交易，保持银行账单确认和已有账务保护。验证原币余额、跨币种转账、历史走势、信用卡退款和校正。
- 附件读取应用有效登录及账本成员校验，开放 API 使用经授权的附件入口。验证未登录、跨账本、撤销成员和老附件。
- 备份与恢复使用一致快照和当前 SQLite 连接。校验候选并在失败时恢复旧库。验证坏文件、连续恢复、恢复后再导出及 WAL 中最新流水。
- 工资等敏感查账用本地规则和叙述。CSV 回导保留引号内换行。演示入口使用现有信用卡还款服务及稳定账户定位。逐项复现并验证。
- 用隔离库运行全量回归、静态检查及受影响页面浏览器复核，更新 API、两份记账技能、看板和归档。
