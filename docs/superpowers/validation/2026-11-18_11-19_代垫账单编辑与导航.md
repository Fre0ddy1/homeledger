# 代垫账单编辑与导航

## 目标与范围

在原代垫账单提供编辑入口，并将「代垫与回收」加到左侧导航。使用当前模型，保留已有本地未跟踪归档。以本地 `62696f7` 为基线，分支为 `codex/advance-edit-navigation`。

## 决策与产出

- 账单行、详情检查器及既有交易编辑路由指向代垫详情中的编辑表单。对象、商家和备注可在未回款、部分回款和收齐后编辑。原有整体更正继续处理金额与自用分配，存在有效回款时页面指明须先撤销回款。
- `src/lib/advances.js` 在同一事务更新代垫和付款分项的展示信息，并同步系统生成的回款说明。保留原 ID、源凭证、实际扣款、余额和回款分项。Web 和授权 API 使用同一服务并记录审计。两份 Agent 技能同步。
- 桌面及手机完整版侧栏的「资产与计划」，以及手机极简「更多」添加管理入口。原账单顶部筛选照常保留在账单页。浏览器测试将同名入口按区域定位。
- 复用既有输入框、按钮、导航和业务测试。验证已收齐后真实保存、原账单状态保留、明暗和桌面/手机、无 JS 及左侧与「更多」入口。
