# 分类 Emoji 扩充

创建：2026-11-12 23:23（Asia/Shanghai）。状态：实施中，持续更新本文件。

## 目标、假设与决策

- 用户认为常用图标太少，明确要求增加Emoji。沿用上一轮已批准的常用平铺＋更多图标展开与自定义输入方案，不新增交互流程或依赖。
- 已核对原组件仅36个图标，其中12个常用；新建/编辑通过同一partial共享，datalist复用同数组。
- 本轮扩为24个常用、96个总量，覆盖餐饮、交通、住房、医疗、学习、宠物、旅行和财务等场景；其余置于既有更多图标。
- 成功标准：新增常用与末尾更多图标均能在新建/编辑正确保存，JS/无JS、明暗主题、手机与宽屏保持可用，取消复位及自定义输入不退化。
- 纯候选集扩充，继续提交icon字符串，不修改数据库/API/Agent技能合同；原有图标不删除，不改变账目。

## 执行与验证计划

1. 最小修改category-icon-picker.ejs候选数组及12→24切分。
2. 在既有浏览器图标任务验证新增常用和更多末尾图标选择、持久化、复位与原生候选；不另建通用选择器框架。
3. 静态、全量回归、定向明暗/390/1920/JS与无JS及全站浏览器验收；人工查看相关截图。
4. 独立审查，PR/Linux CI通过后按授权合并main，补齐本归档。无tag/镜像发布。

## 边界与风险

- Emoji依设备字体绘制；未新增图形素材或外部加载。用户仍可输入面板外表情。
- 沿用现有模态滚动及普通内容自然换行；不新增内部限高滚动。
- 测试只用隔离DATA_DIR，不操作真实data或5111。实体手机Safari不在自动化覆盖范围。
