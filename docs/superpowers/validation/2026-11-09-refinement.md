# 第二轮布局与分类管理验收

分支：`feat/apple-adaptive-ui`。本地开发，未推送、未合并、未发版。
需求与实现约定：[本轮设计](../specs/2026-11-09-layout-and-category-refinement.md)。

## 已完成

- 首页按三列独立堆叠，避免共享行高空洞；中等视口两列、窄屏原始阅读顺序。无 JS 时保留 CSS 分栏。
- 明细工作区主栏不超过 1100px，右侧摘要与详情；默认 20 条，可选 40/80。高级筛选折叠，分页与筛选保留查询条件。窄屏使用详情弹层，桌面右栏有高度约束与内部滚动。
- 玻璃材质用于悬浮侧栏、顶部工具条、菜单与底栏，增加透光背景、边缘高光和鼠标高光反馈；内容保持实色以便阅读，减少动态/透明效果偏好有回退。未引入 WebGL 或声称与原生折射渲染一致。
- 内置与自建分类可编辑、删除和恢复，删除保留数据而非物理清除。一级分类删除会隐藏子树，独立删除的子类不会因父级恢复而复活。
- 首次修改共享分类时生成当前账本副本并迁移引用；全站模板和其他账本不变。旧 ID、历史流水、预算、订阅、周期账单、习惯反馈、词典和导入使用统一对应关系。
- 原有记录和计划可保留已删除分类，新建/新选则排除；按分类预算拒绝空或无效分类，防止统计范围意外扩大。
- 旧版备份热恢复时补齐分类映射表及字段；示例种子先初始化系统分类；浏览器 QA 使用独立 `.tmp/data-ui-browser/` 与 5113 端口，不占用用户 5112 演示实例。

## 验证

- 静态自检：15 通过，0 失败。
- 全量功能回归：21 套全部通过，1088 断言，0 失败；分类套件 `verify-categories.js` 包含 55 断言。
- 浏览器：27 个入口 × 5 宽度 × 2 主题共 270 次，另 25 次起始状态；无横向溢出、无 500、无 pageerror。
- 新增浏览器断言：每列卡片间距 20px、主栏宽度、默认每页记录数、筛选折叠、内嵌详情及焦点返回、跨断点回退、720px 高度长备注操作可达、材质高光、分类编辑/删除/恢复。
- 人工查看新版桌面首页与明细截图，修复窄首页卡片的分类文字换行挤压，图表按卡片宽度调整坐标尺寸。
- 独立代码审查发现的历史分类保留、周期执行口径和详情可达性问题均已修复；预算旧范围残留分类的边界也已收紧并覆盖回归。

功能回归不仅检查页面结构，还验证当前账本隔离、旧 ID、父子恢复、历史金额不变、已软删流水引用、订阅/预算/三种周期 JSON、词典/反馈迁移、异常回滚、只读拒绝和旧备份重新打开。
