# 总览与公共控件统一验收

维护者批准资金进出/消费收支同屏，保留信用卡消费，普通转账排除负债账户；追加以报表切换为例检查全站字体、按钮和跳转。

## 实现

- 总览与极简首页共用两区摘要；月份一致，大屏并排，手机先列流出/流入再列净变化。净资产独立展示，两套数据不相加。两套趋势共同截至所选月份。
- 报表共用 `partials/report-toolbar`，标题、口径导航、月份/日期、方向筛选和年度入口一致；切换及下钻保留日期、年份、方向。日期增强控件限定工具栏内宽度。
- 控件统一继承系统字体，常规和小按钮使用公共字号令牌；预算、订阅、定期、附件、账户、标签等去掉微型按钮覆盖，删除操作使用危险按钮样式。保留标题、金额和辅助文字层级。
- `account-policy` 在普通记账创建/编辑、订阅、定期及导入入口校验；页面、AI草稿、借钱登记/核销同规则筛选。信用卡可消费，贷款/应收/应付退出普通收支；普通转账和借钱本金排除负债账户。
- 金融服务通过独立的可信调用参数创建真实还款/放款；请求体伪造来源不能绕过。银行导入保留已发生还款待核销，避免重复记账。账户 API 新增 `transaction_types`；两份记账技能及金融参考同步。
