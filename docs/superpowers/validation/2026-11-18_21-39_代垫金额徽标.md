# 代垫金额徽标

## 目标与决定

维护者希望账单明细的「自用／代垫」金额更显眼，外观与「待收」和「已收齐」相近。沿用上一轮确定的静态摘要和点行查看路径。金额作为同一个中性色徽标，状态继续由已有的橙色和绿色徽标表达。

## 实施与验收

1. 在 `src/views/partials/txn-list.ejs` 给账单明细代垫主单的摘要 `span` 使用现有 `chip` 样式。该分支沿用 `7cd29b5` 的列表约束。
2. `public/css/workspace.css` 仅对这个徽标加强字色和字重，允许长金额自然换行。首次手机截图出现单独一行的金额，用不换行空格把词组和各自金额连在一起，保留小屏的整组换行。
3. 在 `test/ui-advance-checks.cjs` 检查圆角、徽标颜色区分、长金额宽度，继续实测点击摘要后进入普通详情及共用编辑。验收覆盖明暗主题、窄屏和桌面、JavaScript 和无脚本。

## 结果

- 修改后 8 组隔离 Edge 专项全部通过，覆盖 390px 与 1920px、明暗主题、JS 和无 JS。实看手机浅色、桌面深色截图。证据 `.tmp/advance-split-chip-final-browser.log`、`.screenshots/audit-after/advance-filter-light-390-js.png`、`.screenshots/audit-after/advance-bill-settled-dark-1920-js.png`。
- Windows Node 24、Node 22（UTC）各 32 套、1725 项业务断言通过，静态 15 项通过。证据 `.tmp/advance-split-chip-win24.log`、`.tmp/advance-split-chip-win22-utc.log`、`.tmp/advance-split-chip-static.log`。
- 独立审查通过，无 P1/P2。局部规则只作用于账单明细代垫主行的金额标签。沿用 5112 隔离预览，保留原有三份未跟踪文件。
