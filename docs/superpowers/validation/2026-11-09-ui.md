# 自适应 UI 改版验收记录

日期：2026-11-09。分支：`feat/apple-adaptive-ui`。本地开发改版，未发版、未推送、未部署。

## 实现

- 全站共用设计令牌、卡片、表单、选择器、导航、弹层及明暗主题；玻璃效果用于导航，有实色回退与减少透明效果支持。
- `.content` 取消 1240px 上限，1920px 下主内容宽度 1680px，2560px 下主内容宽度 2320px；大屏三列信息模块，小屏单列，不按屏幕尺寸放大字体。
- 首页收入构成来自现有 SQL 分类统计，不再截掉尾部分类；类别可跳转所选月份的报表下钻。目标显示百分比、已存、目标与剩余金额，零分母保护、进度封顶。前月无基数时显示暂无可比数据。
- 只读成员首页不出现写入入口，流水操作依权限展示。流水可 Enter/Space 打开详情，关闭恢复焦点。
- 菜单状态同步 ARIA；确认与详情弹层限制键盘焦点；抽屉退出移动断点时释放焦点约束。品牌、账本切换和侧栏底部固定，长导航单独滚动。
- 保留现有业务路由、数据结构与安全机制，未新增运行时依赖。

## 页面覆盖

浏览器脚本：`test/verify-ui-browser.cjs`，原始 JSON：`.screenshots/qa.json`。

| 页面类型 | 覆盖入口 |
|---|---|
| 日常 | `/`、`/transactions`、`/transactions/new`、`/calendar`、`/ai`、`/attachments`、`/search` |
| 分析 | `/reports`、`/annual` |
| 账户和计划 | `/accounts`、`/accounts/1`、`/budgets`、`/goals`、`/debts`、`/subscriptions`、`/recurring` |
| 数据和系统 | `/categories`、`/tags`、`/import`、`/export`、`/ledgers`、`/members`、`/notifications`、`/settings`、`/about`、`/more` |
| 错误 | `/not-found`（预期 404） |

以上 27 个入口 × 5 种视口（390/820/1280/1920/2560）× 浅深主题，共 270 次页面检查：无页面横向溢出，无 500，无浏览器 pageerror。表格与横向筛选栏在各自容器内滚动。

另对登录、注册、无账本、有效邀请确认、初始化视觉模板检查五种宽度，共 25 次无溢出。
初始化采用真实 EJS 模板和布局渲染的 fixture，因为已有用户的应用会将 `/setup` 重定向到登录；未重置数据库来模拟首次安装。

键盘/偏好检查通过：用户菜单 Esc 与焦点恢复、交易详情 Enter 与焦点恢复、确认弹层 Tab 约束、抽屉 Esc、打开抽屉后跨桌面断点、减少动态效果、极简模式、1024px 粗指针平板。
200% 缩放使用 1920 物理像素等效配置（960 CSS 像素、DPR 2）验证布局；并非手动操作浏览器缩放菜单。

已人工查看浅色首页、手机首页与深色记账表单截图，确认模块排布、金额、主题文字及表单内容可读。浏览器批量检查用于发现溢出和运行错误，不等于对每个页面的每项业务操作作人工验收；业务行为由回归套件覆盖。

## 重现与预览

`npm run preview:ui`，访问 `http://localhost:5112`，演示账号 `admin / admin123456`。
仅使用 `.tmp/data-ui-preview/`，不打开或修改 `data/homeledger.db`。演示金额为种子数据，产品页面始终展示当前账本真实统计。

可选浏览器测试依赖安装到 `.tmp/ui-qa/`，不进入应用依赖：

```powershell
npm install --prefix .tmp/ui-qa --no-package-lock playwright
node test/verify-ui-browser.cjs
```

测试会关闭其自行启动的浏览器和服务器，不结束其他 Node 实例。
